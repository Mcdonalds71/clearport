Custody of
the file.

Signed-in workspaces have isolated shipment records and PDF attachments. Commercial invoices, supplier unit pricing, bills of lading, and Form M banking dossiers are processed inside tenant-isolated Microsoft Azure infrastructure.

Workspace access
Passphrases use salted cryptographic derivation (PBKDF2 / scrypt) and Microsoft Entra ID SSO for enterprise clearing teams.
Document isolation
Each clearing agency workspace stores its consignments and source PDFs in isolated tenant containers. Public case files are illustrative and strictly separated from customer shipments.
Production Azure architecture
Azure AI Document Intelligence for multi-page OCR extraction, Azure OpenAI for assisted ECOWAS CET classification, and Azure Kubernetes Service (AKS) for workload orchestration.
Encryption & key custody
Azure Blob Storage with AES-256 encryption at rest, TLS 1.3 in transit, and HSM-backed Customer-Managed Keys in Azure Key Vault.
Data protection (NDPA 2023)
Clearport’s enterprise security programme addresses access control, statutory 7-year audit retention, data subject rights, and incident response under the Nigeria Data Protection Act (NDPA) 2023.
